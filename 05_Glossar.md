# Glossar

Hier findest du Erklärungen zu den wichtigsten Begriffen, die in diesem Kurs verwendet werden.

### Editor
Ein Programm zum reinen Schreiben und Bearbeiten von Quellcode (Text). Im Gegensatz zu Textverarbeitungsprogrammen (wie Microsoft Word) fügt ein Code-Editor keine unsichtbaren Formatierungszeichen hinzu und bietet Entwickler-Hilfen wie die farbliche Hervorhebung von Code (Syntax-Highlighting).

### Visual Studio Code
Oft auch kurz **VS Code** genannt. Ein kostenloser, sehr beliebter und schneller Code-Editor von Microsoft. Er ist stark erweiterbar und wird in unserem Kurs als Standard-Werkzeug verwendet. *(Achtung: Nicht zu verwechseln mit der großen, speicherintensiven Entwicklungsumgebung "Visual Studio"!).*

### Workspace
Der Arbeitsbereich in deinem Editor. In VS Code entspricht dies in der Regel dem aktuell geöffneten Hauptordner (Projektordner), in dem sich alle Dateien, Unterordner und Bilder für deine aktuelle Website oder dein aktuelles Projekt befinden.

### Extensions
Zusatzmodule oder Erweiterungen (Plugins), die in VS Code installiert werden können, um neue Funktionen hinzuzufügen. Da VS Code von Haus aus sehr schlank gehalten ist, passen sich Entwickler:innen den Editor über Extensions an ihre spezifischen Bedürfnisse an.

### Live Server
Eine extrem nützliche Extension für VS Code. Sie startet auf Knopfdruck einen lokalen, temporären Webserver auf deinem Computer. Das Besondere: Sie aktualisiert die Webseite im Browser vollautomatisch, sobald du Änderungen an deinen HTML- oder CSS-Dateien abspeicherst (Live-Reload).

### HTML
Steht für **H**yper**t**ext **M**arkup **L**anguage (Hypertext-Auszeichnungssprache). Es ist die fundamentale Sprache des World Wide Web und wird verwendet, um das Grundgerüst und den Inhalt einer Webseite (wie Überschriften, Absätze, Bilder und Links) semantisch zu strukturieren.

### CSS
Steht für **C**ascading **S**tyle **S**heets (Kaskadierende Gestaltungsbögen). Es ist eine Formatierungssprache, die HTML ergänzt. Während HTML für den Inhalt zuständig ist, wird CSS verwendet, um das visuelle Aussehen (Design, Layout, Farben, Abstände, Schriftarten) der Webseite zu gestalten.

### Markdown
Eine sehr einfache, textbasierte Auszeichnungssprache. Sie wird verwendet, um Text ohne komplizierten Code schnell und leicht lesbar zu formatieren (z.B. mit Sternchen für **fett** oder Rauten für Überschriften). In der Softwareentwicklung ist es der Standard für Dokumentationen, Übungsangaben oder `README`-Dateien, da Plattformen wie GitHub diese Dateien automatisch schön darstellen können.

### HTTP
Steht für **H**yper**t**ext **T**ransfer **P**rotocol. Das ist die "Sprache" oder das Regelwerk, mit dem sich Browser (Client) und Server im Internet unterhalten. Der Browser stellt einen HTTP-Request (Anfrage), und der Server antwortet mit einer HTTP-Response (Antwort), die oft HTML-Dateien oder Statuscodes (wie `404 Not Found` oder `200 OK`) enthält.

### RESTful
(Oft auch einfach REST). Steht für **Re**presentational **S**tate **T**ransfer. Es ist ein Design-Muster (eine Architektur-Regel) für die Erstellung von Web-APIs. Wenn eine API "RESTful" ist, bedeutet das, dass sie die klassischen HTTP-Methoden strikt und logisch verwendet, um Daten zu verarbeiten: `GET` zum Abrufen, `POST` zum Erstellen, `PUT` zum Ändern und `DELETE` zum Löschen.

### Start-Tag
Das Eröffnungs-Tag eines HTML-Elements, das dem Browser den Beginn eines Inhaltsbereichs signalisiert. Es wird in spitze Klammern gesetzt (z.B. `<p>`, `<h1>` oder `<div>`) und bestimmt die Art des Elements. Im Gegensatz zum End-Tag besitzt es keinen Schrägstrich. Ein Start-Tag kann zudem Attribute enthalten, um dem Element zusätzliche Informationen oder Eigenschaften bereitzustellen.

### Markdown
Eine extrem simple und weit verbreitete Auszeichnungssprache, um Textdateien zu formatieren. Anstatt auf Menüs und Buttons (wie in Word) zu klicken, nutzt man einfache Textsymbole (wie `#` für Überschriften oder `**` für fetten Text). Wird in der Softwareentwicklung quasi überall für Dokumentationen (wie `.md` Dateien auf GitHub) eingesetzt.

### LaTeX
Eine sehr mächtige Textsatz-Sprache, die besonders im akademischen Umfeld genutzt wird, um wissenschaftliche Arbeiten und komplexe mathematische Formeln (wie Brüche, Wurzeln oder Matrizen) präzise und fehlerfrei darzustellen. 

### Inline
Bedeutet "in derselben Zeile" oder "im fließenden Text". Ein Inline-Element erzeugt keinen neuen Absatz oder Zeilenumbruch. Ein *Inline-Code* in Markdown hebt beispielsweise nur ein einzelnes Wort mitten im Satz als Code-Schriftart hervor.

### Code-Block
Ein eigenständiger, mehrzeiliger Bereich innerhalb eines Dokuments, der Programmcode darstellt. In Markdown wird ein Code-Block meist von drei Backticks umschlossen. Im Gegensatz zu Inline-Elementen steht ein Code-Block optisch als abgetrennter Kasten auf der Seite.
