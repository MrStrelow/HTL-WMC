# Aufgabe: Markdown, Linter & LaTeX

### 🛠️ Aufgabe 1: Linter-Fehler beheben
Betrachte nun das ausgeteilte Skript in deinem Editor mit aktiviertem Linter (VS Code Extension `markdownlint`). 
* Klicke auf die gelb markierten Stellen im Text.
* Lies die Fehlermeldungen (z. B. *"MD009: Trailing spaces"* oder *"MD041: First line in file should be a top level heading"*).
* Behebe fünf Fehler beginnend von oben, bis das gesamte Dokument fehlerfrei ist und keine Warnungen mehr angezeigt werden.

### 🔍 Aufgabe 2: Neue Konzepte entdecken
Durchsuche den rohen Markdown-Code des Skriptums auf Konzepte und Sonderzeichen, welche wir im Unterricht **noch nicht** explizit besprochen haben. 
* Notiere dir "unbekannte" Markdown-Befehle. Es sind hinweise im Skriptum versteckt.
* Beschreibe in einem eigenen markdown file die neu gefunden konzepte. Recherchiere dazu im Internet (oder durch Ausprobieren im Renderer) heraus, was diese Befehle bewirken.

### 📐 Aufgabe 3: Einen echten Wikipedia-Eintrag in LaTeX nachbauen
Nutze einen Online-LaTeX-Editor (z. B. *Overleaf* oder *latexbase.com*). Deine Aufgabe ist es, einen realen Wikipedia-Artikel in seiner Struktur nachzubauen. 

**Vorgehen:**
1. Öffne im Browser den deutschen Wikipedia-Artikel zum Thema **Satz des Pythagoras** (bis zu *Pythagoreische Tripel*) oder **Tim Berners Lee**.
2. Analysiere die Webseite: Wie ist der erste Absatz strukturiert? Was ist eine Überschrift, was ist Fließtext, wie ist die Formel abgesetzt und wie werden Listen dargestellt?
3. Entscheide selbst, welche ``Annotationen`` du benötigst, um diese  Struktur nachzubauen. Achte primär auf die logische Struktur, nicht auf das exakte grafische Design (Schriftart etc.)!
