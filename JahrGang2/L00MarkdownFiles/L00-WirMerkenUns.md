>**Wir merken uns von [Markdown Cheatsheet](L01.3-MarkdownCheatsheet.md):**
>1) [``Markdown``](../../../05_Glossar.md#markdown) formatiert Texte durch simple Sonderzeichen (`#`, `*`, `[]`) und ist der Standard für Dokumentationen (wie READMEs auf GitHub).
>2) Kurzer Code mitten im Text ([``Inline``](../../../05_Glossar.md#inline)) wird mit einem einzelnen Backtick (Gravis) eingefasst, um ihn optisch hervorzuheben.
>3) Mehrzeilige [``Code-Blöcke``](../../../05_Glossar.md#code-block) werden mit drei Backticks umschlossen. Durch die Angabe der Programmiersprache (z.B. `html`) wird der Code farbig markiert.
>4) [``HTML``](../../../05_Glossar.md#html) funktioniert nativ innerhalb von Markdown! Wenn die einfachen Sonderzeichen nicht reichen (z.B. für Textfarben oder exakte Bildgrößen), nutzen wir einfach HTML-Tags.
>5) Für komplexe mathematische Formeln nutzen wir die Wissenschaftssprache [``LaTeX``](../../../05_Glossar.md#latex), welche in Markdown mit Dollarzeichen `$` eingefasst wird.
