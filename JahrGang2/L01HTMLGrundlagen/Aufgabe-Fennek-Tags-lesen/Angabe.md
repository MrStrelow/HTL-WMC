**Aufgabe: Webseiten-Analyse (fennek.mobi)**

**Name:** _______________________
**Datum:** _______________________

**Ziel:** Du untersuchst eine echte Webseite mit den Entwicklertools des Browsers und dokumentierst deine Ergebnisse als Entwickler-Notizen direkt in einer Markdown-Datei.

---

### Aufgabe 1: Vorbereitung
Erstelle in deinem Editor eine neue Datei namens `analyse.md`. In dieser Datei wirst du deine heutigen Ergebnisse festhalten. Strukturiere deine Notizen übersichtlich mit Markdown-Überschriften (`#`, `##`) und Listen (`*`).

### Aufgabe 2: Webseite untersuchen
1. Öffne die Webseite `https://www.fennek.mobi/` in deinem Browser.
2. Nutze die Werkzeuge des Browsers, um den Code sichtbar zu machen:
   * Drücke `Ctrl + U`, um den reinen Seitenquelltext zu sehen.
   * Drücke `F12` (oder `Ctrl + Shift + I`) und wechsle in den "Elements"-Tab, um die Live-Struktur der Seite zu inspizieren.

### Aufgabe 3: Tags dokumentieren
Gehe im Code auf Spurensuche und dokumentiere deine Funde in deiner `analyse.md`.
* Liste mindestens **5 verschiedene HTML-Tags** auf, die du im Code der Seite findest.
* Schreibe zu jedem Tag kurz dazu, **wie** er auf dieser speziellen Seite verwendet wird (z.B. "Dieses Tag umschließt das Logo", "Es baut das Hauptmenü auf", "Es ist ein unsichtbarer Rahmen").

### Aufgabe 4: Unbekannten Code analysieren
Echter Code enthält oft Befehle oder Attribute, die wir im Unterricht noch nicht besprochen haben. Das ist völlig normal!
* Suche dir einen Code-Schnipsel (ein Tag oder eine ganze Zeile) heraus, den du absolut nicht verstehst.
* Kopiere diesen Schnipsel in deine `analyse.md` (formatiere ihn dort sauber als Markdown-Code-Block).
* Schreibe einen kurzen Satz dazu, **was genau** du daran nicht verstehst (z.B. "Ich kenne dieses Attribut nicht", "Warum steht hier dieses Sonderzeichen?", "Was bewirkt dieses Tag?").
